# CarePath: Mental Health Access & Triage System

CarePath is a mental-health access and operations concept designed to help users navigate support options while helping service teams identify demand patterns, wait-time bottlenecks, urgency levels, and follow-up gaps.

## Project Goals
- Map the user journey for someone seeking mental health support
- Design non-diagnostic triage logic for routing users to support levels
- Generate a mock behavioral health access dataset
- Build an operations dashboard around demand, urgency, wait times, and referral flow
- Recommend product and process improvements
